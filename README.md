**Project objective**

Showcase end-to-end business analytics—from historical performance to predictive insights—using interactive dashboards and clean documentation.
________________________________________
**Project Overview**

This project presents a multi-layered analysis of supermarket sales data, combining historical performance metrics, customer segmentation, regional trends, and short-term forecasting. The dashboards are designed to support strategic decision-making across operations, marketing, and supply chain planning.
________________________________________
**Tools Used:**  
Power BI, DAX, Power Query, Excel, SQL
________________________________________
** Dashboards**
- **Supermarket Analysis v1:** Historical performance and segmentation.
- **Supermarket Analysis v2:** Enhanced visuals and updated filters.
- **15 Days Forecast:** Predictive insights with confidence bands.
________________________________________
**Future Enhancements**

•	Integrate Python forecasting models (ARIMA, Prophet) for deeper predictive analytics.
•	Add dynamic filters for year, region, and segment.
•	Automate data refresh via Power BI Service.
•	Include KPI alerts for threshold-based monitoring.
________________________________________
**✅ Conclusion**

This project demonstrates a full-cycle analytics workflow—from data cleaning and transformation to dashboard design and forecasting. It reflects a strong command of business intelligence tools, storytelling through data, and a user-centric approach to visualization.
